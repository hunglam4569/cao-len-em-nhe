## ✨ Giới thiệu

**Cao lên em nhé!** là ứng dụng Progressive Web App (PWA) giúp theo dõi và nhắc nhở lộ trình cải thiện chiều cao theo phương pháp khoa học — bao gồm dinh dưỡng, thể dục, giấc ngủ và đo lường tiến độ.

Được thiết kế với giao diện dễ thương màu hồng pastel, lời nhắc nhẹ nhàng yêu thương — phù hợp để tặng cho người bạn yêu thương của bạn 💌

## 📱 Tính năng

| Tab | Chức năng |
|-----|-----------|
| 🏠 **Hôm nay** | Checklist 9 việc cần làm mỗi ngày, lời chào thay đổi theo giờ, nhập tên cá nhân hóa |
| ⏰ **Nhắc nhở** | 8 lời nhắc từ 6:30 sáng đến 10 tối, bật/tắt từng nhắc nhở |
| 📏 **Chiều cao** | Ghi đo chiều cao theo ngày, biểu đồ tuần, so sánh tiến bộ |
| 💌 **Nhật ký** | Ghi cảm xúc hàng ngày kèm emoji tâm trạng, lưu tối đa 30 bài |
| ⭐ **Thành tích** | Streak ngày liên tiếp, 8 huy hiệu mở khóa, tin nhắn yêu thương |

### 🌟 Điểm nổi bật
- **Không cần cài đặt** — chỉ cần trình duyệt
- **Lưu dữ liệu cục bộ** — dùng `localStorage`, không cần tài khoản
- **Thêm vào màn hình chính** — hoạt động như app thật trên iOS & Android
- **Hoàn toàn miễn phí** — mã nguồn mở, không quảng cáo
- **Lời nhắc dễ thương** — ngôn ngữ nhẹ nhàng, yêu thương, không áp lực

## 🚀 Cài đặt & Sử dụng

### Dùng ngay (không cần cài đặt)
Chỉ cần mở file `cao-len-em-nhe.html` bằng trình duyệt bất kỳ.

### Deploy lên Netlify (2 phút)
1. Vào [app.netlify.com/drop](https://app.netlify.com/drop)
2. Kéo thả file `cao-len-em-nhe.html` vào trang
3. Netlify tự tạo link — gửi cho người thân dùng ngay!

### Deploy lên GitHub Pages
```bash
# 1. Fork repo này
# 2. Đổi tên file thành index.html
# 3. Bật GitHub Pages: Settings → Pages → Source: main
# Link: https://[username].github.io/cao-len-em-nhe
```

### Thêm vào màn hình chính điện thoại

**iPhone (Safari):**
Nhấn nút Chia sẻ → "Thêm vào Màn hình chính" → Thêm

**Android (Chrome):**
Nhấn ⋮ → "Thêm vào màn hình chính" → Thêm

## 📋 Lộ trình cải thiện chiều cao trong app

Ứng dụng tích hợp chương trình 6 tháng dựa trên cơ sở khoa học:

**🥗 Dinh dưỡng**
- Thực phẩm giàu canxi, Vitamin D, protein và kẽm
- Nhắc uống canxi + D3 đúng giờ sau ăn
- Hạn chế cafein, đồ ăn nhanh, thức khuya

**🏋️ Thể dục**
- Treo xà đơn — bài tập hiệu quả nhất để kéo giãn cột sống
- Bơi lội, nhảy dây, yoga kéo giãn
- Lịch tập 6 ngày/tuần, nghỉ Chủ nhật

**😴 Giấc ngủ**
- Nhắc ngủ trước 22:30 mỗi tối
- 80% hormone tăng trưởng tiết ra lúc ngủ sâu (22:00–2:00)
- Nhắc tắt điện thoại lúc 21:30

## 🛠️ Công nghệ sử dụng

- **HTML5** — cấu trúc ứng dụng
- **CSS3** — giao diện responsive, mobile-first
- **Vanilla JavaScript** — logic ứng dụng, không dùng framework
- **localStorage** — lưu dữ liệu người dùng trên thiết bị
- **Google Fonts** — font Nunito dễ thương
- **PWA-ready** — meta tags hỗ trợ thêm vào màn hình chính

> Toàn bộ chỉ là **1 file HTML duy nhất** — không có dependency, không cần build, không cần server.
